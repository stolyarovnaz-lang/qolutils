# QoL Utils (Fabric 1.20.4, client-side)

Build:   gradle wrapper --gradle-version 8.5   (once)   then   ./gradlew build
Run dev: ./gradlew runClient
Jar:     build/libs/qolutils-1.0.0.jar  (drop into .minecraft/mods with Fabric API 0.97.x)

Keys (NumLock ON): KP2 death TP, KP3 auto-eat, KP4 torch, KP5 drop junk,
KP6 auto-tool, KP7 safewalk, KP8 parkour assist.
